# JIKS 통학버스 주거지 찾기

단일 HTML 페이지 (Leaflet + OpenStreetMap). 빌드 없음.

## 배포 (GitHub Pages)
1. 이 폴더 내용을 저장소 루트에 올린다.
2. Settings → Pages → Source를 "GitHub Actions"로 지정한다.
3. main에 푸시하면 `.github/workflows/pages.yml`이 배포한다.

## 구조
- PC: 왼쪽 사이드바(필터·목록) + 오른쪽 지도. 모바일: 지도 / 목록·필터 탭.
- 외부 호출: 지도 타일(OpenStreetMap)과 환율(open.er-api.com, IDR→KRW). 환율은 접속 시 하루 1회 조회해 localStorage에 저장하고, 조회 실패 시 저장값 또는 내장값(2026-11-16)을 쓴다. 노선·역 데이터는 `routes.js`에 내장되어 있다.
- 교통 색: 도시철도(MRT·LRT) 보라, 일반철도(KRL·공항철도·고속철) 회색, 미개통 구간 보라 점선, 통학버스 노선 청록 한 색(마우스를 올린 노선만 굵게).
- 색: 지역 특징은 4색(상업·주거·시설·공단), 단지는 파랑(통과)·회색(제외), JIKS 빨강, 즐겨찾기 노랑. 배경지도는 CARTO Voyager 밝은 컬러 타일이다(API 키 불필요).
- 매물 사진: `photos.js`(`PHB` 단지 사진, `PHU` 매물 코드별 사진). 매물 목록은 Jendela360·Travelio·Rumah123·99.co·Mamikos를 직접 조사해 `index.html`에 넣은 정적 데이터이고 실시간 연동이 아니다. 사진은 각 사이트 이미지 주소를 그대로 쓰며, 불러오기 실패 시 자동으로 숨긴다. 목록 카드·지도 팝업·즐겨찾기 매물에 표시된다.
- 즐겨찾기는 브라우저 localStorage에 저장한다. 단지(★)와 개별 매물(★, 지도 팝업)을 따로 저장하며, 개별 매물은 사이드바 상단 "즐겨찾기 매물 · 환율"에 원화 월세와 월 총액 추정이 표시된다.
- 공과금 추정: 면적 기준(관리비 Rp/㎡, 전기 약 5.2kWh/㎡ × 단가, 물 Rp 100,000 + 1,500/㎡). 관리비·전기 단가는 사이드바에서 조정한다. 실제 청구액과 다를 수 있다.

## 주거 계약 가이드
`housing-guide/index.html` — 인도네시아 임대차 계약 안내와 확인 체크리스트. 배포 후 `/housing-guide/`에서 열린다.

## 통학 버스 노선도·철도
- "통학 버스 노선도": 노선별로 켜고 끈다. 전체 켜기·끄기, 정류장 이름·시각(확대 시) 표시도 따로 고른다. 노선은 정류장을 시간 순서로 이어 JIKS까지 간 도로 경로 추정(OSRM·OpenStreetMap)이며 실제 경로와 다를 수 있다. 노선 번호는 시간표 블록 순서로 추정했다. 점선 원은 단지 위치를 찾지 못한 대략 위치다.
- 철도(LRT·KRL·공항철도·고속철·MRT 2단계)는 "교통 표시"에서 켜고 끈다. 선로는 OpenStreetMap 노선 관계(2026-09-05 기준)의 실제 선로 형상을 단순화한 것이고, 역 좌표도 OSM으로 보정했다. LRT Jakarta는 Manggarai 연장(2026-09-16 개통)까지 포함한다. 역·노선은 `routes.js`의 내장 데이터(`TRS`)이고, BRT 노선·정류장만 Overpass API(키 불필요)로 불러와 7일간 저장한다. 실패하면 안내 문구가 뜬다.
- 데이터는 `routes.js`(`BUSR`, `TRS`). 갱신하려면 해당 변수를 수정한다.

## 기능
생활 조건(필수·선호, 주변 인프라), 자카르타 동네와 한국 비유, 행정구역(Kecamatan·Kelurahan) 경계, 즐겨찾기 메모·상태·내보내기, 통학 버스 노선도, 매물 즐겨찾기·환율·공과금 추정이 모두 한 웹앱에 있다. 헤더의 "계약 가이드"는 `housing-guide/`로 이동한다.
