# JIKS 통학버스 주거지 찾기

정적 웹앱 (Leaflet + OpenStreetMap). 빌드 없음. 구조와 설계 이유는 `docs/ARCHITECTURE.md`.

## 배포 (GitHub Pages)
1. 이 폴더 내용을 저장소 루트에 올린다.
2. Settings → Pages → Source를 "GitHub Actions"로 지정한다.
3. main에 푸시하면 `.github/workflows/pages.yml`이 배포한다. 같은 워크플로가 6시간마다 매물을 확인하고 다시 배포한다(Actions 탭에서 수동 실행 가능).

## 구조
- 화면은 주소(#/…)로 나뉜다. `#/find` 찾기(조건·결과·매물 확인 현황) · `#/mine` 내 후보(즐겨찾기·환율·공과금·전체 백업) · `#/area` 지역·교통(지역 구분·동네 안내·철도·통학버스 노선·시간표) · `#/guide` 계약 가이드(`#/guide/check` 체크리스트) · `#/c/<단지 id>` 단지로 이동. 모바일은 같은 탭 줄의 `#/map`이 지도.
- 파일: `index.html`(뼈대) · `css/app.css`·`css/guide.css` · `js/core`(공통·라우터) · `js/data`(단지·지역·경계·노선·사진 데이터) · `js/features`(기능별) · `js/main.js`(초기화).
- 외부 호출: 지도 타일(OpenStreetMap 기본, Esri·OSM HOT 선택. CARTO는 API 키 요구로 제외)과 환율(open.er-api.com, IDR→KRW). 환율은 접속 시 하루 1회 조회해 localStorage에 저장하고, 조회 실패 시 저장값 또는 내장값(2026-11-16)을 쓴다. 노선·역 데이터는 `js/data/routes.js`에 내장되어 있다.
- 교통 색: 도시철도(MRT·LRT) 보라, 일반철도(KRL·공항철도·고속철) 회색, 미개통 구간 보라 점선, 통학버스 노선 청록 한 색(마우스를 올린 노선만 굵게).
- 색: 지역 특징은 4색(상업·주거·시설·공단), 단지는 파랑(통과)·회색(제외), JIKS 빨강, 즐겨찾기 노랑. 배경지도는 CARTO Voyager 밝은 컬러 타일이다(API 키 불필요).
- 매물: 조사 목록은 `js/data/places.js`. `scripts/update-listings.mjs`가 6시간마다 각 매물 페이지를 열어 게시 여부·가격을 확인하고 Jendela360 단지 페이지에서 새 매물을 찾아 `data/listings.json`을 만든다. 앱은 이 파일을 열 때와 30분마다 읽어 내려간 매물·가격 변동·새 매물을 팝업·목록·즐겨찾기·필터에 반영하고, 헤더와 "찾기" 탭에 확인 시각을 표시한다. 사이트가 막거나 시간이 초과되면 이전 상태를 유지한다.
- 매물 사진: `js/data/photos.js`(`PHB` 단지 사진, `PHU` 매물 코드별 사진, 새 매물은 사이트 대표 이미지). 사진은 각 사이트 이미지 주소를 그대로 쓰며, 불러오기 실패 시 자동으로 숨긴다. 목록 카드·지도 팝업·즐겨찾기 매물에 표시된다.
- 즐겨찾기·메모·생활 조건·설비 기록·공과금 단가는 브라우저 localStorage에 저장하고, "내 후보"의 전체 백업으로 한 파일에 내보내고 가져온다. 단지(★)와 개별 매물(★, 지도 팝업)을 따로 저장하며, 개별 매물은 사이드바 상단 "즐겨찾기 매물 · 환율"에 원화 월세와 월 총액 추정이 표시된다.
- 공과금 추정: 면적 기준(관리비 Rp/㎡, 전기 약 5.2kWh/㎡ × 단가, 물 Rp 100,000 + 1,500/㎡). 관리비·전기 단가는 사이드바에서 조정한다. 실제 청구액과 다를 수 있다.

## 주거 계약 가이드
인도네시아 임대차 계약 안내와 확인 체크리스트는 앱 안 `#/guide`에 있다(`js/features/guide.js`, `css/guide.css`). 예전 주소 `/housing-guide/`는 앱으로 넘겨준다. 체크 상태도 전체 백업에 들어간다.

## 통학 버스 노선도·철도
- "통학 버스 노선도": 노선별로 켜고 끈다. 전체 켜기·끄기, 정류장 이름·시각(확대 시) 표시도 따로 고른다. 노선은 정류장을 시간 순서로 이어 JIKS까지 간 도로 경로 추정(OSRM·OpenStreetMap)이며 실제 경로와 다를 수 있다. 노선 번호는 시간표 블록 순서로 추정했다. 점선 원은 단지 위치를 찾지 못한 대략 위치다.
- 철도(LRT·KRL·공항철도·고속철·MRT 2단계)는 "지역·교통" 탭에서 켜고 끈다. 선로는 OpenStreetMap 노선 관계(2026-09-05 기준)의 실제 선로 형상을 단순화한 것이고, 역 좌표도 OSM으로 보정했다. LRT Jakarta는 Manggarai 연장(2026-09-16 개통)까지 포함한다. 역·노선은 `routes.js`의 내장 데이터(`TRS`)이고, BRT 노선·정류장만 Overpass API(키 불필요)로 불러와 7일간 저장한다. 실패하면 안내 문구가 뜬다.
- 데이터는 `js/data/routes.js`(`BUSR`, `TRS`). 갱신하려면 해당 변수를 수정한다.
- 단지·학원 데이터는 `js/data/places.js`, 지역 데이터는 `js/data/regions.js`.

## 기능
생활 조건(필수·선호, 주변 인프라), 자카르타 동네와 한국 비유, 행정구역(Kecamatan·Kelurahan) 경계, 즐겨찾기 메모·상태·내보내기, 통학 버스 노선도, 매물 즐겨찾기·환율·공과금 추정이 모두 한 웹앱에 있다. 헤더의 "계약 가이드"는 `housing-guide/`로 이동한다.
